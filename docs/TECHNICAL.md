# 구조와 수정

- BIGFILE: 3,376개 항목. 수정 항목 648개, 재배치 없음. ISO와 파일 LBA 유지.
- 메뉴 1,178개 레코드. CP932와 E1 A0 xx 아이콘 제어 바이트를 구분해 보존.
- MUL 자막은 일본어 채널만 수정하며 블록 길이와 16바이트 정렬을 재계산. 다른 언어·음성·영상·타이밍 보존.
- 일반 글꼴은 원본 19×19 일본어 슬롯에 한글 851자 배치. 팔레트와 나머지 글리프 보존.
- 조작 그림 4종은 두 개의 256×256 타일로 해석해 글자 영역만 수정.
- 영상 자막 SCH는 별도 형식. 크기 하한 없이 모든 항목의 헤더를 검사해 1개 파일, 19개 대사를 추출. 시각과 영어 채널 보존.
- 영상 전용 글꼴: BIGFILE 783번, 실행 파일 오프셋 0x29ac20의 180개 문자표. 한글 133자와 영문 채널의 원본 문자 47자를 같은 공간에 재배치. 영문 문자 픽셀 보존. ELF 코드와 문자표 밖 데이터 유지.
- 영상과 음성 스트림은 재인코딩하지 않음. ISO 크기 4,201,054,208 바이트 유지.

기존 레전드 패치의 아카이브·아이콘 처리 방식을 참고했으나 본 작품의 항목 번호, 글꼴, 영상 자막 형식은 별도로 분석했습니다.
